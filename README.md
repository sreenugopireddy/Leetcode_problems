# LeetCode Problems

This repository contains my daily LeetCode problem-solving practice.

Every problem is organized in its own folder, and the solution along with my approach/explanation is added to that problem's individual README file.

## Structure

Each folder is named after the problem and contains:
- The solution code
- A README explaining the approach

## Goal

Solving problems consistently, one day at a time, to improve my problem-solving and DSA skills.
